# A-5 [API Key 관리] 코드·로그·이미지 키 grep · 서비스별 env
# 환경: docker compose · 2026-11-09 15:45 KST · 결과: 미발견
# 값은 출력하지 않는다 — 변수 이름과 건수만 기록

## 1. 서비스별 환경변수 (이름만)
$ docker exec <서비스> printenv | cut -d= -f1 | grep -E "OPENAI|TAVILY|API_KEY"
jobgap-backend-1     : (없음)
jobgap-ai-service-1  : OPENAI_API_KEY TAVILY_API_KEY
jobgap-frontend-1    : (없음)
jobgap-database-1    : (없음)
$ grep -n -E "OPENAI_API_KEY|TAVILY_API_KEY" docker-compose*.yml
docker-compose.yml:28:      OPENAI_API_KEY: ${OPENAI_API_KEY}      # ai-service 블록에만 · 기본값 없음
docker-compose.yml:29:      TAVILY_API_KEY: ${TAVILY_API_KEY}

## 3. 로그
$ docker logs jobgap-backend-1 2>&1 | grep -c -E "sk-...|tvly-..."      → 0

## 4. 이미지
$ docker image inspect <이미지> --format '{{range .Config.Env}}...' | grep -E "OPENAI|TAVILY|API_KEY|SECRET|PASSWORD"
jobgap-backend / jobgap-ai-service / jobgap-frontend : (없음 — 키는 이미지에 굽지 않고 실행 시 env로만 주입)
