4) 필드 전부 누락 {}
400 · "fields":[{"field":"name","message":"must not be blank"},{"field":"email","message":"must not be blank"},{"field":"password","message":"must not be blank"}]

노출 검사(Exception|at com.|java.|SQL|stack 등): 4건 모두 0 · 모두 400이라 계정은 만들어지지 않음

실행 메모: 첫 시도에서 1)을 curl -d 인라인(한글 name)으로 보냈을 때 400인데 fields가 없었다.
          Windows 명령줄에서 한글 인자가 UTF-8로 전달되지 않아 서버가 JSON 형식 오류(400, fields 없음)로 본 것 — 같은 내용을 UTF-8 파일(1)과
          ASCII 이름(2)으로 보내면 fields가 나온다. 서버 결함이 아니라 클라이언트 인코딩 문제로 판단.
