- DOM: img[src="x"] 0 · script 0 · javascript: href 0

## ④ CSP 응답 헤더 — 실제 Docker Compose 환경

검증일: 2026-11-09

검증 환경: Docker Compose (nginx → frontend)

실행 명령:

`curl.exe -sI http://localhost/ | findstr /i "content-security"`

실제 응답:

`Content-Security-Policy: default-src 'self'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'self'`

기대값:

`default-src 'self'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'self'`

검증 결과:
- Content-Security-Policy 헤더 존재 확인
- 실제 응답값과 기대값 일치
- 판정: **PASS**
- 상세 증거: `security/evidence/F-1-csp.txt`

## 최종 결과

- XSS 화면 재현: 대화상자(alert) 발생 0회 · 콘솔 에러 0 → 테스트한 입력에서 XSS 실행 미발견
- 문서 제목·질문·AI 응답의 HTML 문자열이 실행되지 않고 텍스트로 표시됨
- 위험한 `javascript:` 출처 URL이 클릭 가능한 링크로 생성되지 않음
- 실제 nginx 응답의 CSP 헤더가 프로젝트 기대값과 일치함

**최종 판정: PASS**
