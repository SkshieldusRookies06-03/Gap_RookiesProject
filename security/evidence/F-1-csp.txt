## 3) CSP — nginx/default.conf (설정 파일 정적 확인)
server 블록 + location = /index.html 두 곳에 같은 값 (location 안 add_header는 상속이 끊기므로 다시 적어 둠):
  add_header Content-Security-Policy "default-src 'self'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'self'" always;
  add_header X-Content-Type-Options "nosniff" always;
  add_header Referrer-Policy "no-referrer" always;
→ script-src 미지정 = default-src 'self' (인라인 스크립트·외부 스크립트 차단) · 'unsafe-inline'·'unsafe-eval' 없음

## 4) CSP 실제 응답 헤더 — Docker Compose 검증 (사용자 직접 실행 · 2026-11-09 KST)
환경: Docker Compose (nginx → frontend) · http://localhost/
$ curl.exe -sI http://localhost/ | findstr /i "content-security"
Content-Security-Policy: default-src 'self'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'self'
→ 위 3)의 nginx/default.conf 설정값과 일치 · 'unsafe-inline'·'unsafe-eval' 없음 → PASS
