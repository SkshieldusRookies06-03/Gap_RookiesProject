## D. 실제 HTTP 500 — BLOCKED
- 위 C의 요청은 모두 4xx로 매핑된다 — 500 응답 본문은 관측하지 못했다.
- onboarding §9.3의 B-8 방법(깨진 JSON 로그인)은 현재 코드에서 400이다. docs/9 B-8 행 "잘못된 JSON 본문 등 500 유발"과 코드가 다르다.
- 코드·DB를 바꾸지 않고 500을 내는 승인된 방법이 없다. DB 컨테이너 중지·데이터 조작·코드 변경 등 임의 재현은 하지 않았다.

## 판정: BLOCKED
- 정적·단위 테스트·실서버 4xx 오류 응답 7종: 노출 미발견
- 실제 HTTP 500 응답 본문: 미관측 → 기술 리드가 500 재현 방법을 정해 주면 같은 노출 검사로 확정
