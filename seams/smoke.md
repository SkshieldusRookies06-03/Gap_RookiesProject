# smoke.md — 화면 사람 눈 검사 (게이트가 못 보는 것 · 매일 1회 · 오너가 자기 줄)

> 목(`node mock/server.mjs` + `npm run dev`) 또는 compose(`http://localhost`)에서 브라우저로 본다. 통과한 줄 번호를 PR 본문에 적는다.
> 뷰포트는 390(모바일) 하나 이상과 1280을 본다. 콘솔 에러 0이 모든 줄의 전제다.

| # | 화면 | 순서 | 통과 기준 | 오너 |
|---|---|---|---|---|
| 1 | 로그인 | 틀린 비밀번호 → 맞는 비밀번호 | 사용자 문구("이메일 또는 비밀번호…") → `/documents` 이동 · 새로고침해도 로그인 유지 | FE-화면 |
| 2 | 회원가입 | 이메일 형식 틀림·비밀번호 3자 → 정상 | 필드 아래 문구 · 성공 후 로그인 화면 | FE-화면 |
| 3 | 내 문서 목록 | 탭(전체/공고/이력서) · 정렬 · 다음 페이지 | 빈 상태 문구 · 로딩 표시 · 제목 `<img src=x onerror=alert(1)>`가 글자로 보임 | FE-화면 |
| 4 | 업로드·수정·삭제 | `.md` 업로드 → 제목 수정 → 삭제 · `.exe`·300KB 시도 | 안내 문구 · 삭제 확인 · 409/413/415 사용자 문구 | FE-화면 |
| 5 | 분석(새) | 공고·이력서 선택 → 분석 시작 → 중단 → 다시 시작 | 토큰이 **흘러나온다**(한꺼번에 아님) · 생성 중 표시 · 표가 표로 · 출처 칩 문서/웹 구분 | FE-분석 |
| 6 | 분석(후속·재진입) | 후속 질문 → 기록에서 다시 열기 | 지난 대화가 먼저 보이고 이어서 질문 · 웹 출처 링크는 새 탭 | FE-분석 |
| 7 | 분석 기록 | 목록 → 클릭 | 중단된 분석은 "중단됨" · 클릭 시 해당 분석 | FE-화면 |
| 8 | 공통 | 390·768·1280 | 가로 스크롤 0 · 내비가 줄바꿈돼도 겹치지 않음 · 로그아웃 동작 | FE-화면 |
