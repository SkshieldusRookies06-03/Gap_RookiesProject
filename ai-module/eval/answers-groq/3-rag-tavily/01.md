## 준비 순서

1. **Docker 활용** – 컨테이너 기반 배포를 위한 Dockerfile 작성, Docker Compose 활용 경험 습득  
2. **AWS 배포** – EC2 인스턴스, RDS 데이터베이스 설정 및 CI/CD 파이프라인 구축 경험  
3. **JWT 인증 구현** – Spring Security와 JWT를 이용한 토큰 기반 인증 흐름 구현  
4. **클라우드 인프라 모니터링** – CloudWatch, ELK 스택 등 로그·모니터링 도구 활용  
5. **CI/CD 자동화** – GitHub Actions / GitLab CI 등으로 자동 빌드·테스트·배포 파이프라인 구축  

> **순서**는 현재 “없음”인 기술부터 시작해 “부분”인 기술(예: Spring Security 기초)까지 차례대로 진행하도록 구성했습니다.
