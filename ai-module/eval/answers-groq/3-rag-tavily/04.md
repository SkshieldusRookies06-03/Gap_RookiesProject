> **주요 결론**  
> - 백엔드 개발에 필요한 핵심 기술(백엔드 언어, 프레임워크, DB, API 설계)은 전혀 보유하고 있지 않음.  
> - REST API 연동 경험은 있으나 설계 경험은 부족함.  
> - 인프라·컨테이너, 지리정보 처리 경험도 전무.

## 준비 순서

1. **백엔드 언어( Kotlin/Java )와 Spring Boot 학습**  
   - 기초 문법 → 프레임워크 구조 → REST 컨트롤러 구현  
2. **PostgreSQL 데이터베이스 설계 및 쿼리 실습**  
   - ER 다이어그램 작성 → 스키마 정의 → CRUD 쿼리 작성  
3. **REST API 설계 원칙 및 문서화**  
   - 엔드포인트 설계, HTTP 메서드, 상태 코드, Swagger/OpenAPI 활용  
4. **AWS(EC2, S3)와 Docker 기반 배포**  
   - EC2 인스턴스 생성 → Dockerfile 작성 → CI/CD 파이프라인 구축  
5. **지도·위치 데이터 처리**  
   - Google Maps API, GeoJSON, 좌표 변환 등 실습  

> **Tip**: 프론트엔드 경험을 활용해 풀스택 프로젝트를 진행하면 학습 효과가 배가됩니다.
