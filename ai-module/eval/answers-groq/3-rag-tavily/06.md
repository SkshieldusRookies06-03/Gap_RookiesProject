## 준비 순서
1. **TypeScript** – 기초 문법·타입 시스템 학습 → 기존 React 코드에 타입 적용  
2. **Next.js** – SSR, API 라우트, 파일 기반 라우팅 학습 → Next.js 프로젝트 구축  
3. **Jest / Testing Library** – 컴포넌트 단위 테스트 작성 → 테스트 커버리지 80% 이상 목표  
4. **Storybook** – 컴포넌트 라이브러리 구축 및 문서화 → 디자인 시스템과 연동  
5. **통합 실습** – TypeScript + Next.js + Jest + Storybook 으로 작은 서비스 개발 → 포트폴리오에 추가
