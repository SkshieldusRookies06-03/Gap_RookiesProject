## 준비 순서

1. **MySQL 사용 경험**  
   - PostgreSQL 경험이 있으므로 MySQL에 대한 기본 문법과 차이점 학습 → 온라인 튜토리얼 및 실습 프로젝트 수행  
2. **Airflow 배치 스케줄링**  
   - cron 기반 스크립트 실행 경험이 있으므로 Airflow DAG 작성 및 모니터링 실습 → 작은 ETL 파이프라인 구축  
3. **대시보드 도구 (Tableau/Superset)**  
   - 시각화 경험이 없으므로 Tableau Public 또는 Superset 설치 후 간단한 대시보드 제작 → 데이터 시각화 기초 학습  
4. **Docker 기반 배포**  
   - 현재 Docker 사용 경험이 없으므로 Dockerfile 작성 및 컨테이너 실행 실습 → FastAPI 프로젝트를 Docker화해 보기  
5. **AWS 기반 데이터 파이프라인**  
   - AWS 경험이 없으므로 S3, RDS, Glue 등 기본 서비스 사용법 학습 → 간단한 데이터 파이프라인 구축 실습
