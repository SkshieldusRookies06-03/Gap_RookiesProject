## 준비 순서

1. **TypeScript**  
   - React 프로젝트에 TypeScript를 도입해 타입 안정성을 확보합니다.  
   - 공식 문서와 실습 예제를 통해 기본 문법과 타입 정의를 익히세요.

2. **Next.js**  
   - SSR(서버 사이드 렌더링)과 정적 사이트 생성(SSG)을 활용한 Next.js 프로젝트를 하나 만들어 보세요.  
   - API 라우트, `getServerSideProps`, `getStaticProps` 등을 실습합니다.

3. **Jest / Testing Library**  
   - 컴포넌트 단위 테스트를 Jest와 React Testing Library로 작성해 보세요.  
   - 테스트 커버리지와 CI에 통합하는 방법을 익히면 우대 조건 충족에 큰 도움이 됩니다.

4. **Storybook**  
   - 재사용 가능한 UI 컴포넌트를 Storybook에 등록해 문서화합니다.  
   - Addons(Accessibility, Knobs 등)를 활용해 접근성 테스트와 인터랙션을 시각화해 보세요.

5. **Lighthouse**  
   - 실제 서비스에 배포하기 전 Lighthouse를 활용해 성능, 접근성, SEO 점수를 측정하고 개선합니다.  
   - 개선 포인트를 기록해 두면 포트폴리오에 활용할 수 있습니다.

> **Tip**: 각 단계별로 작은 프로젝트를 만들어 GitHub에 공개하면 포트폴리오에 바로 활용할 수 있습니다.
