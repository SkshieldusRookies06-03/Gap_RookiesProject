## 준비 순서

1. **Docker 기초 학습** – Dockerfile 작성, 이미지 빌드, 컨테이너 실행  
2. **AWS EC2에 Docker 배포** – EC2 인스턴스 생성, Docker 설치, Spring Boot 컨테이너 배포  
3. **AWS RDS MySQL 연결** – RDS 인스턴스 생성, 보안 그룹 설정, Spring Boot에서 연결 테스트  
4. **JWT 기반 인증 구현** – Spring Security와 JWT 토큰 발급/검증 로직 구현  
5. **CI/CD 파이프라인 구축** – GitHub Actions로 Docker 이미지 빌드 → ECR → EC2 배포 자동화

> **우선순위**  
> 1. Docker → 2. AWS 배포 → 3. RDS 연결 → 4. JWT 인증 → 5. CI/CD
