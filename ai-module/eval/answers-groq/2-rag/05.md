## 준비 순서

1. **TypeScript 기초 학습**  
   - TypeScript 문법, 타입 정의, React와의 연동 방법을 학습합니다.  
2. **Redux 기초 학습**  
   - Redux Toolkit 사용법, 상태 관리 흐름을 이해하고 작은 프로젝트에 적용해 봅니다.  
3. **React + TypeScript 프로젝트**  
   - TypeScript를 적용한 React 앱을 만들어 보며 타입 안정성을 경험합니다.  
4. **테스트 및 성능 최적화**  
   - Jest·Testing Library를 활용한 단위/통합 테스트 작성과 Lighthouse를 이용한 성능 개선을 연습합니다.  
5. **포트폴리오 업데이트**  
   - TypeScript와 Redux를 사용한 프로젝트를 포트폴리오에 추가하고, GitHub에 공개합니다.
