## 요구 기술

| 기술 | 공고 근거 | 보유 여부 | 이력서 근거 |
|------|-----------|-----------|-------------|
| Java | Java, Spring Boot 사용 경험 | 보유 | Java 17, Java 백엔드 과정, 프로젝트에서 사용 |
| Spring Boot | Java, Spring Boot 사용 경험 | 보유 | Spring Boot 3, 동네 도서 대여 서비스 및 개인 블로그 API에서 사용 |
| Redis | Redis를 이용한 캐시 구현 경험 | 없음 | 근거 없음 |

> **주의**  
> - 공고에 명시되지 않은 기술은 포함하지 않았습니다.  
> - 이력서에 명시되지 않은 기술은 “근거 없음”으로 표시했습니다.

## 준비 순서

1. **Redis 캐시 구현 경험 습득**  
   - Redis 설치·연동, 캐시 전략 설계 및 구현 실습  
2. **Kafka 메시지 큐 이해 및 실습**  
   - Kafka 클러스터 구성, 프로듀서/컨슈머 구현, 토픽 관리  
3. **Kubernetes 환경 배포 경험**  
   - Docker 이미지 빌드 → Kubernetes 클러스터에 배포, 서비스/인그레스 설정  
4. **대용량 거래 이벤트 처리 및 성능 개선**  
   - 비동기 처리, 파티셔닝, 스케일링 전략 학습 및 적용  
5. **테스트 코드 작성 습관 강화**  
   - JUnit 외에 Spring Test, MockMvc, Integration Test 등 확장

> **순서**는 “없음·부분인 기술”부터 시작해, 이후 성능·배포·테스트 영역으로 확장하도록 설계했습니다.
