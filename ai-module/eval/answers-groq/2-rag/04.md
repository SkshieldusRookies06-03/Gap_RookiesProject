## 준비 순서

1. **Kotlin/Java 기초 학습**  
   - 언어 문법, 객체지향 개념, 표준 라이브러리 활용  
   - 간단한 콘솔 프로그램부터 시작해 점차 복잡도 증가  

2. **Spring Boot + PostgreSQL 연계**  
   - Spring Boot 기본 구조, 의존성 주입, JPA/Hibernate 활용  
   - PostgreSQL 연결, CRUD REST API 구현  
   - 테스트 코드 작성(예: JUnit, Spring Test)  

3. **Docker & AWS 활용**  
   - Dockerfile 작성, 컨테이너화, docker‑compose로 로컬 개발 환경 구성  
   - AWS EC2 인스턴스에 배포, S3 버킷을 이용한 정적 파일 저장  

4. **REST API 설계 역량 강화**  
   - REST 원칙(URI 설계, HTTP 메서드, 상태 코드) 숙지  
   - OpenAPI(스웨거) 스펙 작성 및 문서화  
   - 인증/인가(예: JWT) 및 에러 처리 패턴 구현  

5. **지도·위치 데이터 처리**  
   - Google Maps API, Mapbox 등 지도 서비스 SDK 활용  
   - 위치 기반 기능(경로 탐색, 좌표 변환, 반경 검색) 구현  
   - 실시간 위치 추적
