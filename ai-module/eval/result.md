## 채점 메모
- 채점: 1차 구본영 · 2차 윤동호 · 불일치 1칸(9번 ②)은 팀장 김영서 판정 → O
- 결과 기준: S-04 조치(11/10)·리포트 형식 변경(11/11) **전** 프롬프트로 실행한 답변
- 기준: 기술 문항 = 정답 기술 전부 + 보유 여부가 이력서와 일치 + 공고에 없는 기술을 지어내지 않음 · 웹 문항 = 정답 문구 · 근거 = 답변 본문에 공고, 이력서 인용 또는 출처 URL
- ① LLM 단독: 공고를 못 봐서 '기술 A, B, C'처럼 빈 틀을 채우고 "관련 자격증 보유" 같은 근거를 지어냄(환각), 웹 문항은 "근거 없음"
- ②: 웹 문항(3·7·10)은 공고·이력서에 답이 없어 "근거 없음"으로 답함 — 지어내지 않음(정상 동작)
- 9번 ②: 1차 X(이력서에 "Docker 실무 경험 없음"인데 Docker를 '부분'으로 판정) · 2차 O(문항 정답 = 요구 기술 목록을 모두 맞힘) → 팀장 판정 O · Docker '부분'은 보유 판정 오류로 개선 과제에 남김(같은 문항 ③은 '없음'으로 정확)
- 7번 ③: 정답은 맞혔으나 답변 본문에 출처 URL이 없음 → 근거 X
- 10번 ③: 정답지(2026 프레스톡 'AI 네이티브 뱅크')와 다른 실제 발표(KodeRunner 2026 'AI가 일하는 은행')를 출처와 함께 답함 → 정답지 기준 X · 문항이 넓어 정답이 여러 개일 수 있음(개선 과제)
