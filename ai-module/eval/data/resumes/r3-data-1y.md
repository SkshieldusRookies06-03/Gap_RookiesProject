# 이력서 C — 데이터 엔지니어 지원 (경력 1년)

> ※ AI 답변 채점용 **가상 이력서**입니다. 실존 인물·연락처와 관계없습니다.

- 희망 직무: 데이터 엔지니어 / AI 서비스 백엔드

## 경력

### (주)가상물류 — 데이터 분석 인턴 → 사원 (2024.03.04 ~ 2025.02.28)

- 일 단위 배송 데이터(약 30만 행) 정제·집계 스크립트를 Python·Pandas로 작성
- 수작업 엑셀 보고서를 SQL 쿼리 + Python 스크립트로 바꿔 주간 보고 작성 시간을 4시간에서 30분으로 단축
- cron으로 스크립트를 매일 새벽 실행 (실패 알림은 없어 다음 날 수동 확인)

## 학력

- 다온대학교 통계학과 졸업 (2018.03 ~ 2024.02)

## 기술

- 언어: Python 3.11, SQL
- 데이터: Pandas, NumPy, Matplotlib
- DB: PostgreSQL (조회·집계 위주), SQLite
- 웹: FastAPI (기초 — 토이 프로젝트 1개)
- AI: OpenAI API 호출, LangChain 기초 (RAG 실습)
- 도구: Git, Jupyter, VS Code, Linux 셸 기초

## 프로젝트

### 사내 문서 질의응답 챗봇 — 개인 토이 프로젝트 (2025.05)

- FastAPI + LangChain + Chroma로 PDF 사내 규정 문서를 검색해 답하는 API
- 청크 크기 500자 / 300자 비교 실험 후 500자 선택
- 아쉬운 점: 로컬에서만 실행, Docker 이미지나 배포는 하지 않음

### 배송 지연 예측 — 개인 분석 프로젝트 (2024.10)

- 날씨·요일·지역 변수로 지연 여부 분류 (로지스틱 회귀, 정확도 0.78)
