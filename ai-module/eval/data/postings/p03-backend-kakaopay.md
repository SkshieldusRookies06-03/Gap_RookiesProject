## 회사 소개
- 간편결제·송금·금융 서비스를 운영하는 핀테크 회사

## 주요 업무
- 결제 승인·취소 처리 서버 개발
- 파트너사가 쓰는 결제 API 개발
- 대량 결제 데이터를 처리하는 배치 개발

## 자격 요건
- Java 또는 Kotlin 사용 경험
- Spring Boot 사용 경험
- MySQL 등 관계형 DB 사용 경험
- 자료구조·알고리즘·네트워크 기초 지식

## 우대 사항
- Kafka 등 메시지 큐를 이용한 비동기 처리 경험
- 테스트 코드(단위·통합 테스트) 작성 경험
- AWS 사용 경험
- Docker, Kubernetes 사용 경험

## 근무 조건
- 신입 (경력 무관)
- 근무지: 경기 성남(판교)
