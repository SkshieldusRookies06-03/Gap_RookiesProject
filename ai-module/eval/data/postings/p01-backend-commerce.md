# [백엔드 신입] (주)가상커머스

> ※ AI 답변 채점용 **가상 공고**입니다. 실제 회사·공고와 관계없습니다.

## 회사 소개
- 온라인 쇼핑몰 플랫폼을 운영하는 직원 50명 규모의 회사

## 주요 업무
- 주문·결제 REST API 개발 및 운영
- 상품 관리용 사내 관리자 시스템 개발
- 서비스 장애 대응 및 로그 분석

## 자격 요건
- Java, Spring Boot 사용 경험
- JPA를 이용한 데이터베이스 연동 경험
- MariaDB 또는 MySQL 사용 경험
- Git을 이용한 협업 경험

## 우대 사항
- Docker로 서비스를 실행해 본 경험
- AWS(EC2, RDS) 배포 경험
- JWT 기반 로그인 구현 경험

## 근무 조건
- 신입 (경력 무관)
- 근무지: 서울
