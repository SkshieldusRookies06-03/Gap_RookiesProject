## 1. 프로젝트 개요

### 1.1 프로젝트명

**JobGap — 취업 갭 분석 리포트** (JobGap: Job Posting × Resume Gap Analyzer)

### 1.2 프로젝트 목적

취업 준비생이 채용공고와 자기 이력서를 올리면, 공고가 요구하는 기술과 이력서의 보유 기술 차이를 **근거(문서 조각·웹 출처)와 함께**
리포트로 스트리밍하고, 같은 화면에서 후속 질문("부족한 것부터 뭘 공부해?")을 이어 가게 한다. 이력서는 개인정보 덩어리이므로
LLM에 보내기 전에 연락처를 가리고, 남의 문서에는 접근할 수 없게 하는 것을 기능만큼 중요하게 둔다.

| 3대 목적 | 이 서비스에서 달성하는 방법 |
|---|---|
| LLM 연동 | FastAPI AI 모듈의 RAG(Chroma · 사용자별 owner 필터) + LangGraph 조건 분기(검색 점수 낮으면 Tavily) → SSE 토큰 스트리밍을 Spring이 화면까지 중계 |
| 안전한 백엔드 | JWT(Access/Refresh 분리 · Refresh 해시 저장·회전) · 소유자 검증(IDOR 차단) · 로그인 잠금 · 업로드 검증 · 개인정보 마스킹 · OWASP 점검서 31행 |
| 배포 | Dockerfile 3 · compose 1벌(외부 공개 80 하나, 망 3개) · Flyway · GitHub Actions · EC2 |

## 3. 기술 스택

- **Backend**: Spring Boot 3.3 · Java 17 · Maven · Spring Data JPA · Spring Security · WebClient(SSE 중계) · Flyway
- **Frontend**: React 18 · Vite · React Router · Zustand · CSS Modules · PropTypes
- **AI/ML**: FastAPI · LangChain · LangGraph · OpenAI(`gpt-4o-mini` · `text-embedding-3-small`) · Tavily
- **Database**: MariaDB 10.11 · Chroma(벡터)
- **Security**: Spring Security · JWT · BCrypt · CSP · 로그인 잠금 · 개인정보 마스킹(`PiiMasker`) — 값은 `SPEC.md` §1 표
- **Infrastructure**: Docker · Docker Compose · nginx · GitHub Actions · AWS EC2

## 6. 성공 기준

| 기준 | 확인 방법 |
|---|---|
| 1. 문서 업로드 → AI 분석 → 스트리밍 응답이 화면까지 끝까지 동작한다 | 브라우저 E2E(가입→업로드→분석) 영상 · `node seams/check-api.mjs http://<EC2>` green |
| 2. 다른 사용자의 문서·분석에 접근할 수 없다 | `AnalysisAcceptanceTest`·`DocumentAcceptanceTest` 403 행 green · S-01 재확인 캡처 `security/evidence/S-01/` |
| 3. 비밀정보가 코드·Git 이력에 없다 | `node scripts/check-sec-deploy.mjs` 무출력(이력 포함) |
| 4. 외부에는 80만 열려 있고 AI·DB 포트는 닫혀 있다 | 외부에서 `curl -m 3 http://<EC2>:8080`·`:8000`·`:3306` 실패 캡처 |
| 5. `docker compose up` 한 번으로 전체가 뜬다 | `docker compose ps` 전부 healthy 캡처 · README 실행 절차 |
| 6. 보안 점검표 전 행이 근거와 함께 채워졌다 | `security/LEDGER.md` 31행 결과 칸 · `git log --grep='\[S-0'` |
| 7. CI/CD로 이미지가 빌드·배포된다 | GitHub Actions green 화면 · 이미지 태그 = 커밋 해시 |
